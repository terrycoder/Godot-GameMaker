## 3. 静态校验

- 六份文档围栏计数均为偶数。
- `--studio-game` 只在两处否定警示中出现、命令块零命中；不存在的 `gm_runtime/planar3d`、旧 `%BUILD_OUT%\game_planar3d*`、`tar -xf` 零命中。`findstr` 只在“不要用 findstr+tar 冒充安全解包”的警示中出现。
- `release_profile = candidate`、`current_view_result()`、`[editor_plugins]` 和 P27 真实 2D deny 根均存在。
- 相对文档链接目标与抽核源码/报告路径存在；未引入本机绝对路径作为开发要求。
- ID 示例保留合法类型前缀；错误顺序只在明确“错误示例”语境出现。

## 4. 剩余限制

- 当前可引用的独立运行验收只有 CAW-owned Planar3D 冻结 EXT11 适配；它不验证项目自有 Manifest，也不构成模块中立 PlayerShell SDK。
- 通用 2D bootstrap、项目 composition root、安全解包工具和项目候选 runner 尚无现成公共实现；文档将其作为必须实现/验收的交付门，不再给伪命令。
- CAW runtime copy 禁用编辑器插件；Dock 制作需要平台发布者另发依赖闭合的 editor SDK。
- Godot 4.6.2 是当前验证基线；4.7.2、其他平台、真实资产预算仍未验证。
- HX1 不是 PASS，8 组 GUI/真人验收及 DN-01/DN-02/TN-01 继续保留。

## GitHub 清洁发布版边界

本文件保留平台功能、架构与研究价值；涉及历史测试环境的内容不代表本发布树可直接执行。GitHub 清洁发布版的 CLI 以当前 `gm_cli.gd` 帮助为准，只提供 `help`、`environment`、`compatibility`、`validate`、`modules` 五个只读命令。源仓库内部的测试、插件冒烟、导出冒烟、模块专项验收、GUT、测试目录、fixture、runner 与审查证据均不随本清洁版提供；接收方应在自己的游戏仓库建立测试与发布流水线。
