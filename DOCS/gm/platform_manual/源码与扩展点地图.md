# GM 平台源码地图

## 1. 使用说明

本表帮助开发者定位真实实现，但不把所有类都承诺为稳定公共 API。

- **Public extension point**：预期由项目组合、实现接口或提供 Resource；仍须遵守 schema/Manifest。
- **Internal implementation**：可阅读和验证，不建议下游直接继承、替换或修改。
- **Sample/fixture**：复制结构后必须换项目身份；不得原样发布。
- **Contract/evidence**：测试和封存边界，不是运行时依赖。

所有路径均相对仓库根。

## 12. API 稳定性声明

本文确认的是当前实现边界，不是永久 ABI。现有 CAW 只验证冻结 EXT11 Planar3D 适配；没有模块中立 PlayerShell、通用 2D bootstrap 或会自动消费项目 Index 的入口。自有 Manifest 必须由项目 composition root 在 Registry 首读前选择，并在 Runtime 后检查 committed view。其余优先集成面仍是经目标版本验证的 Resource schema、类型前缀 ID、Manifest/Registry、Ability request、事务/空间/Simulation/atomic contributor 合同。

## GitHub 清洁发布版边界

本文件保留平台功能、架构与研究价值；涉及历史测试环境的内容不代表本发布树可直接执行。GitHub 清洁发布版的 CLI 以当前 `gm_cli.gd` 帮助为准，只提供 `help`、`environment`、`compatibility`、`validate`、`modules` 五个只读命令。源仓库内部的测试、插件冒烟、导出冒烟、模块专项验收、GUT、测试目录、fixture、runner 与审查证据均不随本清洁版提供；接收方应在自己的游戏仓库建立测试与发布流水线。
